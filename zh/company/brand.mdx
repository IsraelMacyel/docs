## 标志的起源

VirtusCloud 的标志经过精心设计，反映了我们公司的价值观和目标。它由两个以特定角度定位的正方形组成，外观类似于"Docker 容器"。

### 标志背后的含义

1. **两个立方体**：两个正方形代表我们构建云基础设施的坚实基础。每个正方形象征着我们服务的健壮性和可靠性。

2. **Docker 容器**：正方形的定位经过精心选择，以唤起 Docker 容器的形象——这是云计算世界中广泛使用的技术。

### 灵活的基础设施

我们公司诞生于创建一个高度灵活的云平台的愿景，能够满足各种规模企业不断变化的需求。

#### 我们基础设施的主要特点：

1. **弹性**：我们的基础设施设计为垂直和水平扩展。
2. **可移植性**：就像 Docker 容器可以在不同环境中运行一样，我们的服务可以轻松迁移。
3. **敏捷性**：基于容器技术，我们可以快速部署解决方案。
4. **可扩展性**：两个正方形也代表我们服务的可扩展性。

### 我们的在线域名

- [virtuscloud.app](https://virtuscloud.app)：我们的主域名。
- [dash.virtuscloud.app](https://virtuscloud.app/dashboard)：仪表板访问。
- [api.virtuscloud.app](https://api.virtuscloud.app)：我们的 API 域名。
- [virtusapp.cloud](https://virtuscloud.app)：连接客户项目与世界的官方域名。

我们还拥有以下域名：
- virtuscloud.org -> virtuscloud.app
- virtuscloud.dev -> virtuscloud.app
- virtuscloud.xyz -> virtuscloud.app
- virtuscloud.email -> virtuscloud.app

## 结论

VirtusCloud 的标志不仅仅是一个简单的视觉表示。它封装了我们公司提供灵活可靠云基础设施的理念和承诺。
