# 🤔 VirtusCloud "教程"是什么？

- 我们的教程是必不可少的资源，旨在引导您从基本工具（如托管 Discord 机器人）到更高级的工具（如使用 Selenium 并在 VirtusCloud 上托管）。准备好掌握拉丁美洲最大企业托管平台上可用的所有工具。

## 📚 教程内容是什么？

- 教程包括 VirtusCloud 上可用的工具，如 Discord、Telegram、Flask 构建的 API 等平台的应用程序。
- 每篇文章都教您如何以对开发者最佳的方式在 VirtusCloud 上创建、配置和托管您的应用程序。
- 我们根据用户需求和工具发展不断更新和创建新教程。如果您想建议添加一篇文章，可以在我们的 [Discord 社区](https://discord.gg/virtuscloud)提出，团队成员将回应您的请求，或在我们的[文档仓库](https://github.com/virtuscloudofc/docs)中提交 pull request。
