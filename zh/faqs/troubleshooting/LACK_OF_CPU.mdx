## 何时发生？

当您的应用程序使用的 CPU 超过可用量时会发生此问题。

```bash
[SQUARE-SHIELD] LACK_OF_CPU
```

## 为什么发生？

当应用程序负载过重或未优化以使用更少 CPU 时会发生此情况。

## 如何修复

分配给应用程序的 CPU 由您当前的计划决定。考虑在[计划页面](https://virtuscloud.app/pricing)升级到更高的计划。或者，优化您的应用程序以减少 CPU 使用。

### 重新提交您的应用程序

升级计划后，删除并重新提交应用程序以反映更新的 CPU 分配。

如果您继续遇到问题，请[联系我们的支持团队](/company/support)。
