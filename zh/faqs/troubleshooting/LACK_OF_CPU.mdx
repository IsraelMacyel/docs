## 何时发生？

当您的应用程序使用的 CPU 超过可用量时会出现此问题。

```bash
[VIRTUS-SHIELD] LACK_OF_CPU
```

## 为什么发生？

当您的应用程序消耗的 CPU 超过可用量时会出现此问题。这可能发生在应用程序处于高负载下，或者应用程序未优化以使用更少 CPU 的情况下。

## 如何修复

分配给您应用程序的 CPU 由您当前的计划决定。要解决此问题，请考虑在[计划页面](https://virtuscloud.app/pricing)升级到更高级别的计划。或者，优化您的应用程序以减少 CPU 使用量。

### 重新提交您的应用程序

升级计划后，需要删除应用程序并重新提交，以反映更新的 CPU 分配。

如果您继续遇到任何问题，请随时[联系我们的支持团队](/company/support)。
