**VirtusCloud** 以其**动态 IP 分配**脱颖而出，每次**应用程序重启**时分配**唯一地址**。

## 何时发生？
当您尝试将 MongoDB Atlas 数据库连接到 VirtusCloud 上托管的应用程序时：

```
MongoNetworkError: connection 0 to shard-xxx-xxx.mongodb.net:27017 closed
```

## 为什么发生？
如果您没有将 MongoDB Atlas 地址包含在白名单中，将收到此错误消息。

## 如何修复
根据 [MongoDB 文档](https://www.mongodb.com/docs/atlas/security/ip-access-list/)，您需要将 IP `0.0.0.0/0` 加入白名单。
