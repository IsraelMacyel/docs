## 未授权

有 2 种情况可能导致此消息：

1. 您尝试访问的网站 URL 未在 VirtusCloud 上托管。如果您在部署应用程序后添加了"SUBDOMAIN"字段，该字段将不被读取，因为它只在部署期间读取。您需要删除并重新部署正确配置了此字段的应用程序。

2. 如果您最近托管了站点，请等待 1 分钟。VirtusCloud 正在完成站点配置。此期间后，请重试访问。

## 超时

有 4 种情况可能导致此消息：

1. 您的网站或 API 可能存在阻止其正确响应的错误。

2. 如果网站或 API 离线，您也会收到此消息。

3. 在 VirtusCloud 中，网站和 API 的默认端口是 HTTP 流量的 `80` 端口。

4. 如果托管站点时未将主机正确配置为 `0.0.0.0`，可能会导致访问错误。
