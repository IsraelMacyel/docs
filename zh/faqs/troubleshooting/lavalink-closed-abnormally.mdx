## 何时发生？
当您尝试将 Lavalink 服务器连接到 VirtusCloud 上托管的应用程序时：

```
Error: Unexpected server response: 400
Error: WebSocket closed abnormally with code 1006.
```

## 为什么发生？
如果您使用的 Lavalink 版本与您使用的库不兼容，将收到此错误。

## 如何修复
将您的 Lavalink 客户端更新到最新版本，或使用与您的 Lavalink 客户端兼容的 Lavalink 版本。

### 额外提示：
- 记住在端口 80 上开放您的 Lavalink 服务器。
- 使用端口 443 和 `secure: true` 选项连接到您的 Lavalink 服务器。

如果您继续遇到问题，请[联系我们的支持团队](/company/support)。
