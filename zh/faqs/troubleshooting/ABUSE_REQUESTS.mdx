## 何时发生？

当您的应用程序因向 Discord 和/或 Amino API 发出大量请求而被关闭时，会发生 ABUSE_REQUESTS 错误。

```bash
[SQUARE-SHIELD] ABUSE_REQUESTS
```

## 为什么发生？

当您的应用程序超过向 API 发出请求的允许限制时会发生此错误。

## 如何修复

### 监控和优化代码

- 使用日志工具识别生成大量 API 请求的代码部分。
- 优化 API 调用，最小化不必要的请求。

### 实施缓存机制

- 使用本地缓存存储频繁请求的数据。
- 设置缓存过期时间。

### 保持应用程序更新

```bash 更新 discord.js
npm install discord.js@latest
```

```bash 更新 discord.py
pip install discord.py
```
