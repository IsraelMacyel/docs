## 何时发生？

当 `better-sqlite3` 库或依赖它的库（如 `quick.db`）未更新时会发生此问题。

```bash
Error: Could not locate the bindings file. Tried:
 → /application/node_modules/better-sqlite3/build/better_sqlite3.node
 [...]
```

## 为什么发生？

此错误发生是因为 `better-sqlite3` 库未更新到最新版本。在 **11.x.x 及更早版本**中，该库**不支持 Node.js LTS v22**。

## 如何修复

将 `better-sqlite3` 库更新到最新版本。记得更新依赖它的库，如 `quick.db`。

### 更新 `package.json`

```json 手动更新 package.json
"better-sqlite3": "^11.10.0",
"quick.db": "^9.1.7"
```

```bash 使用终端更新
npm install better-sqlite3@latest
```

### 删除文件进行干净安装

删除 `node_modules`、`package-lock.json` 和 `.npm` 文件夹。

### 重启您的应用程序

点击蓝色按钮重启您的应用程序。
