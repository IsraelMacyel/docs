## 何时发生？
您的 Discord 机器人的身份验证令牌未找到或看起来无效。

```bash discord.js
Error [TOKEN_INVALID]: An invalid token was provided.
```

```bash discord.py
LoginFailure: Improper token has been passed.
```

## 为什么发生？
当您的应用程序尝试使用无效或过期的机器人令牌向 Discord API 进行身份验证时会出现此错误。

## 如何修复

### 重新生成令牌
如果当前令牌无效，请在 [Discord 开发者门户](https://discord.com/developers/applications) 生成新令牌。

### 更新代码中的令牌
如果您使用 `.env` 文件，请用新令牌更新它。

### 保持库更新

```bash 更新 discord.js
npm install discord.js@latest
```

```bash 更新 discord.py
pip install discord.py
```

如果您继续遇到问题，请[联系我们的支持团队](/company/support)。
