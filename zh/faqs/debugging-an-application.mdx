## 在 [**discord.js**](https://old.discordjs.dev/#/docs/discord.js/14.14.1/class/Client?scrollTo=e-debug) 中调试
使用 discord.js，您可以使用"debug"和"error"事件进行调试。示例如下：

```js
// 客户端监听 'debug' 事件
client.on('debug', (info) => {
    console.log(`调试信息：${info}`);
});

// 客户端监听 'error' 事件
client.on('error', (error) => {
    console.error(`遇到错误：${error.message}`);
});
```

## 在 [**discord.py**](https://discordpy.readthedocs.io/en/stable/logging.html?highlight=debug) 中调试
使用 discord.py，您可以使用 logging 模块进行调试。示例如下：

```py
import logging
import logging.handlers

logger = logging.getLogger('discord')
logger.setLevel(logging.DEBUG)
logging.getLogger('discord.http').setLevel(logging.INFO)

handler = logging.StreamHandler()
dt_fmt = '%Y-%m-%d %H:%M:%S'
formatter = logging.Formatter('[{asctime}] [{levelname:<8}] {name}: {message}', dt_fmt, style='{')
handler.setFormatter(formatter)
logger.addHandler(handler)

client.run("您的令牌", log_handler=None)
```
在此代码中，所有调试信息和错误都记录到控制台。
