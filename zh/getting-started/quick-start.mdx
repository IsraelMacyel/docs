## 上传您的项目 😁
您可以按照以下简单步骤将项目上传到 VirtusCloud：

<Steps>
  <Step title="首先，阅读您所用编程语言的说明：">
    <Snippet file="languages.mdx" />
    <Info>在本示例中，我们将使用 JavaScript (Node.js) 语言。</Info>
  </Step>
  <Step title="然后，创建您的 VirtusCloud 配置文件。">
    访问控制台后，您需要创建一个配置文件。您可以通过阅读[此文章](/getting-started/config-file)来创建[配置文件](/getting-started/config-file)。

    ```systemd 机器人配置文件示例
    MAIN=index.js
    MEMORY=512
    VERSION=recommended
    DISPLAY_NAME=Batman bot
    DESCRIPTION=这个机器人是夜晚的黑暗骑士。
    ```

    ```systemd Web 应用配置文件示例（URL 配置为 "batman.virtusapp.cloud"）
    MAIN=index.js
    MEMORY=512
    VERSION=recommended
    SUBDOMAIN=batman
    START=npm run build && npm run start
    DISPLAY_NAME=Batman website
    DESCRIPTION=这个网站是夜晚的黑暗骑士。
    ```
  </Step>
  <Step title="接着，将项目压缩为 ZIP。">
    创建配置文件后，您需要压缩您的项目。
    <CodeGroup>
      ```bash Windows
      1. 找到要压缩的文件或文件夹。
      2. 右键单击，选择"发送到"→"压缩（zipped）文件夹"。
      3. 将在同一位置创建同名的新压缩文件夹。
      ```
      ```bash Linux
      1. 找到要压缩的文件或文件夹。
      2. 右键单击并从快捷菜单中选择"压缩"。
      3. 将在同一位置创建同名的新压缩文件夹。
      ```
      ```bash macOS
      1. 找到要压缩的文件或文件夹。
      2. 按住 Ctrl 单击并从快捷菜单中选择"压缩"。
      3. 将在同一位置创建同名的新压缩文件夹。
      ```
    </CodeGroup>
  </Step>
  <Step title="最后，上传您的项目。😉">
    上传项目后，单击"添加新项目"按钮来部署您的项目。
  </Step>
</Steps>
