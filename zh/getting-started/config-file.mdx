## 配置文件是什么？🤔
配置文件包含应用程序的参数，如主文件、内存、版本和其他参数。该文件用于在 VirtusCloud 平台上配置和部署您的应用程序。

## 创建配置文件
创建配置文件非常简单：只需创建一个名为 `virtuscloud.app` 或 `virtuscloud.config` 的文件，并在其中输入配置参数。

<Steps>
    <Step title="选择扩展名">
        配置文件可以有两种扩展名：**.app** 或 **.config**。您可以选择您喜欢的扩展名。提示：使用 **.app** 来帮助推广 VirtusCloud (virtuscloud.app)。😂
        <Info>在 **macOS** 上，我们建议使用 **.config** 扩展名。</Info>
        <Warning>注意：**.app** 或 **.config** 是**文件扩展名**，而**不是文件名**。</Warning>
    </Step>
    <Step title="创建文件">
        使用所选扩展名创建文件，并在其中输入配置参数。
    </Step>
</Steps>

## 配置参数
以下是您可以在配置文件中使用的配置参数。

<Steps>
    <Step title="MAIN [*]" icon="file">
        **MAIN** 参数用于定义应用程序的主文件。
        ```systemd 示例：
        MAIN=index.js
        ```
        ```systemd 也支持子目录。
        MAIN=src/loaders/index.js
        ```
        <Info>此参数最多 **32 个字符**。</Info>
        <Info>如果使用 START 参数，此配置将被**忽略**。</Info>
    </Step>
    <Step title="MEMORY [*]" icon="memory">
        **MEMORY** 参数用于定义应用程序在 VirtusCloud 平台上使用的内存量。
        ```systemd
        MEMORY=256
        ```
        <Info>值以兆字节 (MB) 为单位。</Info>
        <Note>机器人的最小内存为 **256MB**，网站为 **512MB**。</Note>
    </Step>
    <Step title="VERSION [*]" icon="arrow-up-9-1">
        **VERSION** 参数用于定义应用程序的版本。
        ```systemd
        VERSION=recommended
        ```
        <Info>每种语言都有不同的版本，请参见下表。</Info>
        | 语言                     | `recommended` 版本     | `latest` 版本    |
        | ------------------------ | ---------------------- | ---------------- |
        | JavaScript [Node.js]     | 22.18.0                | 24.5.0           |
        | Python                   | 3.13.6                 | 3.13.6           |
        | Java                     | JDK 23                 | JDK 25           |
        | Elixir                   | 1.18.4                 | 1.18.4           |
        | Rust                     | 1.89.0                 | 1.89.0           |
        | PHP                      | 8.4.11                 | 8.4.11           |
        | Go                       | 1.24.6                 | 1.24.6           |
        | C#                       | 9.0.1                  | 9.0.1            |
        | HTML/CSS                 | Build 10-02-2025       | Build 10-02-2025 |

        <Tip>我们建议使用 `recommended` 版本，因为我们的团队对所有推荐版本进行了广泛测试。</Tip>
    </Step>
    <Step title="DISPLAY_NAME [*]" icon="text">
        **DISPLAY_NAME** 参数用于定义应用程序的名称。
        ```systemd 示例：
        DISPLAY_NAME=Admin BOT
        ```
        <Info>此参数最多 **32 个字符**。</Info>
    </Step>
    <Step title="DESCRIPTION" icon="text">
        **DESCRIPTION** 参数用于定义应用程序的描述。
        ```systemd 示例：
        DESCRIPTION=该机器人旨在帮助您完成日常任务。
        ```
        <Info>此参数最多 **280 个字符**。</Info>
    </Step>
    <Step title="AUTORESTART" icon="rotate">
        **AUTORESTART** 参数用于定义应用程序崩溃时是否自动重启。
        ```systemd 示例：
        AUTORESTART=true
        ```
        <Info>默认情况下，此参数设置为 `false`。</Info>
    </Step>
    <Step title="SUBDOMAIN" icon="globe">
        **SUBDOMAIN** 参数用于定义网站的子域名。
        ```systemd 示例：
        SUBDOMAIN=mysite
        ```
        <Info>此参数最多 **63 个字符**。</Info>
        <Note>网站 URL 将为：mysite.virtusapp.cloud</Note>
    </Step>
    <Step title="START" icon="play">
        **START** 参数用于为应用程序定义自定义启动命令。
        ```systemd 示例：
        START=npm run start
        ```
        <Info>此参数最多 **256 个字符**。</Info>
        <Info>此参数**忽略** MAIN 参数。</Info>
        <Info>2025 年 6 月 19 日后上传的应用程序可以编辑此字段而无需重新上传</Info>
    </Step>
</Steps>


## 机器人配置示例

```systemd 此示例仅使用必需参数。（最小配置）
MAIN=index.js
MEMORY=256
VERSION=recommended
DISPLAY_NAME=Robin bot
```

```systemd 此示例包含所有参数。
MAIN=index.js
MEMORY=256
VERSION=recommended
DISPLAY_NAME=Robin bot
DESCRIPTION=Robin 是一个旨在帮助您完成日常任务的机器人。
AUTORESTART=true
```

## 网站配置示例

<Info>网站 URL 将为：mysite.virtusapp.cloud</Info>
```systemd 此示例使用所有参数和自定义启动命令。
MAIN=index.js
MEMORY=512
VERSION=recommended
DISPLAY_NAME=我的网站!
DESCRIPTION=我的网站非常棒！
SUBDOMAIN=mysite
START=npm run build && npm run start
AUTORESTART=true
```

## 参数限制

| 参数          | 字符限制      |
| ------------- | ------------- |
| MAIN          | 32 个字符     |
| DISPLAY_NAME  | 32 个字符     |
| DESCRIPTION   | 280 个字符    |
| START         | 256 个字符    |
| SUBDOMAIN     | 63 个字符     |
