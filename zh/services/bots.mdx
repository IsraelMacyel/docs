**VirtusCloud** 是一个先进的技术平台，以提供全面的机器人支持而著称。本文深入介绍 **VirtusCloud** 所提供的机器人功能与支持。

## 功能与支持

<CardGroup cols={1}>
  <Card title="多平台支持" icon="robot">
    **VirtusCloud** 支持 **Discord**、**Telegram**、**WhatsApp**、**Guilded**、**Slack**、**Messenger**、**Facebook** 和 **Twitch** 等主流平台，让开发者灵活选择最适合目标用户的平台。
  </Card>
  <Card title="高级音乐支持" icon="music">
    **VirtusCloud** 通过支持 **ffmpeg** 和 **Lavalink** 来提升机器人的音乐体验。**ffmpeg** 在 **VirtusCloud** 上默认提供，便于实现音乐功能。
  </Card>
  <Card title="高效本地数据库" icon="database">
    **VirtusCloud** 的文件系统设计快速可靠，支持高效使用本地数据库，无需外部数据库服务。
  </Card>
  <Card title="动态托管" icon="rocket">
    **VirtusCloud** 提供动态智能的机器人托管服务，拥有大量公共 IP 地址，确保机器人始终在线可用。
  </Card>
  <Card title="优化延迟" icon="bolt">
    **VirtusCloud** 位于佛罗里达州坦帕市，平均延迟仅 20ms，确保机器人快速响应。
  </Card>
  <Card title="高效图片存储" icon="cloud">
    对于需要存储大量图片的机器人，**VirtusCloud** 提供 **Blob** CDN，支持图片、视频等文件类型的存储。
  </Card>
  <Card title="高级安全性" icon="shield">
    **VirtusShield** 提供额外的安全保障，防止机器人超出 API 请求限制，并提供实时监控。
  </Card>
  <Card title="Git 自动部署" icon="code">
    **VirtusCloud** 支持通过 GitHub 和 GitLab Webhook 实现自动部署。详情请见[此处](https://docs.virtuscloud.app/tutorials/how-to-set-up-git-integration)。
  </Card>
  <Card title="高级路由" icon="star">
    **VirtusCloud** 提供通往 **WhatsApp**、**Telegram** 和 **Discord** 等主要通信中心的优质网络路由。
  </Card>
</CardGroup>

## 如何在 VirtusCloud 上托管我的机器人？

<Steps>
  <Step title="配置文件" icon="file">
    第一步是创建详细的配置文件。详情请见[此处](https://docs.virtuscloud.app/getting-started/config-file)。
  </Step>
  <Step title="创建 ZIP 文件" icon="file-zip">
    将应用程序文件和配置文件放入 .zip 文件中。无需包含 `node_modules`、`package-lock.json` 等文件。
  </Step>
  <Step title="依赖文件" icon="box">
    在 .zip 中包含依赖文件（Node.js 为 `package.json`，Python 为 `requirements.txt`）。
  </Step>
  <Step title="上传机器人" icon="arrow-up">
    访问 **VirtusCloud** 的上传页面并提交您的 .zip 文件，[点击这里](https://virtuscloud.app/dashboard/upload)。
  </Step>
  <Step title="常见部署错误" icon="x">
    <Warning>如遇未列出的错误，请[联系我们](https://virtuscloud.app/dashboard/support)。</Warning>
    <AccordionGroup>
      <Accordion title="INVALID_DEPENDENCY" icon="box">依赖文件在 .zip 中缺失。</Accordion>
      <Accordion title="FEW_MEMORY" icon="memory">RAM 配置不正确（机器人最低 256MB）。</Accordion>
      <Accordion title="INVALID_MAIN" icon="file-code">main 文件不存在或路径错误。</Accordion>
      <Accordion title="MISSING_CONFIG" icon="file-signature">配置文件不在 .zip 中或不在根目录。</Accordion>
      <Accordion title="FAILED_UPLOAD" icon="x">.zip 文件有问题，请检查是否正确创建且未设置密码。</Accordion>
    </AccordionGroup>
  </Step>
</Steps>
