## Introdução

- Antes de começar a programar, você precisa configurar seu bot corretamente no Discord. Primeiro, é necessário ter uma conta no Discord. Se ainda não tiver, crie uma visitando o [site oficial do Discord](https://discord.com/).
- Em seguida, você precisará criar uma conta na VirtusCloud, o que pode ser feito pela [página de cadastro](https://virtuscloud.app/signup). Você pode usar seu e-mail para criar uma conta.
- Por fim, você precisa ter um plano pago ativo na sua conta. Veja nossos planos e adquira um de acordo com suas necessidades [aqui](https://virtuscloud.app/pricing).

# Usando bibliotecas para criação do bot
<Tabs>
  <Tab title="Discord.js">
    1. Certifique-se de ter o Node.js instalado no seu sistema. Se não tiver, baixe-o do [site oficial do Node.js](https://nodejs.org/).
2. Inicialize um novo projeto Node.js usando `npm init`. Isso criará um arquivo `package.json` para o seu projeto:

```bash
npm init -y
```

3. Instale a biblioteca discord.js usando npm:

```bash
npm install discord.js
```

4. Crie um novo arquivo JavaScript (ex.: `index.js`) e adicione o seguinte código para criar um bot básico:

```javascript index.js
const { Client, GatewayIntentBits } = require("discord.js");

const client = new Client({
  intents: [
    GatewayIntentBits.Guilds,
    GatewayIntentBits.GuildMessages,
    GatewayIntentBits.MessageContent,
  ],
});

client.on("ready", () => {
  console.log(`${client.user.tag}!`);
});

client.on("messageCreate", (message) => {
  if (message.content === "!hello") {
    message.reply("Olá!");
  }
});

client.login("seu token aqui");
```
  </Tab>
    <Tab title="Discord.py">
    1. Certifique-se de ter o Python instalado no seu sistema. Se não tiver, baixe-o do [site oficial do Python](https://www.python.org/).
    2. Instale a biblioteca discord.py usando pip:

```bash
pip install discord.py
```

3. Crie um novo arquivo Python (ex.: `main.py`) e adicione o seguinte código:

```python main.py
import discord
from discord.ext import commands

intents = discord.Intents.default()
intents.message_content = True

client = commands.Bot(command_prefix='!', intents=intents)

@client.event
async def on_ready():
    print(f'{client.user}')

@client.command()
async def hello(ctx):
    await ctx.reply('Olá!')

client.run('seu token aqui')
```

4. Crie um arquivo `requirements.txt` listando as bibliotecas externas necessárias:

```txt requirements.txt
discord.py
```

</Tabs>

## Configurando o campo START
<Warning>Use este campo apenas se tiver certeza do que está fazendo.</Warning>

No arquivo de configuração da VirtusCloud, o campo **START** é opcional e necessário apenas se você usar um script personalizado para iniciar o bot. No exemplo fornecido, o campo **START** não é necessário.

## Enviando seu projeto para a VirtusCloud

Após seguir todos os passos, compacte os arquivos da sua aplicação em um arquivo zip contendo o arquivo de configuração e faça o upload em [Upload](https://virtuscloud.app/dashboard/upload). Lembre-se de incluir o arquivo `requirements.txt` ou `package.json`, mas não inclua pastas como `__pycache__` ou `node_modules`. Saiba mais sobre arquivos desnecessários em [exclusão automática de arquivos ao hospedar uma aplicação na VirtusCloud](https://docs.virtuscloud.app/faqs/automatic-file-deletion-when-deploying-an-application-on-virtuscloud).

## Testando o Bot

Se tudo foi feito corretamente, o próximo passo é convidar seu bot para testes. Siga estes passos:

1. Acesse o [Portal do Desenvolvedor](https://discord.com/developers/applications).
2. Selecione seu bot.
3. Navegue até a aba "OAuth2".
4. Vá em "OAuth2 URL Generator".
5. Marque a opção "bot".
6. Escolha as permissões que seu bot terá ao ser convidado.
7. Abaixo das permissões, um link de convite será gerado, parecido com:
```txt
https://discord.com/oauth2/authorize?client_id=00000000000000&permissions=8&scope=bot
```

Lembre-se de substituir `client_id` pelo ID real do seu bot e ajustar o valor de `permissions` conforme necessário.

Para testar, execute o seguinte comando no seu servidor: `!hello`.
