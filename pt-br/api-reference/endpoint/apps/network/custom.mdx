# Set Custom Domain

> Integrate your website with a custom domain. It has a rate limit of 1 request every 60 seconds.

**Is necessary to have at least the [Standard plan](https://virtuscloud.app/en/pricing) to use this route.**

<ParamField header="Authorization" type="string" placeholder="API Key" required>
  The API key for your account. You can find this in your [account settings](https://virtuscloud.app/account/security).
</ParamField>

<ParamField path="app_id" type="string" placeholder="Application ID" required>
  The ID of the application. You can find this in the URL of your application's dashboard.
</ParamField>

<ParamField body="custom" type="string" placeholder="example.com" required>
  The custom domain you want to use.
</ParamField>

### Response

<ResponseField name="status" type="string">
  Indicates whether the call was successful.. `success` if successful, `error` if not.
</ResponseField>

<ResponseExample>
  ```json theme={null}
  {
      "status": "success"
  }
  ```
</ResponseExample>
