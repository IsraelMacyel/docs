# Getting Started on Virtus Cloud with Rust

> Learn how to get started on Virtus Cloud with Rust

## 🚀 Introduction

* Before getting started, ensure that Rust is installed on your system. If you don't have it yet, you can download it from the [official Rust website](https://www.rust-lang.org/tools/install).
* Next, you will need to create an account on Virtus Cloud, which can be done through the [login page](https://virtuscloud.app/en/signup). You can use your email, GitHub, or both to create the account.
* Finally, you need to have an active paid plan on your account. You can view our plans and purchase one according to your needs [here](https://virtuscloud.app/en/pricing).

## ⚙️ virtuscloud.app file configuration

<Note>
  If you are uploading your application via the Virtus Cloud website, you can ignore this section. The site automatically creates the `virtuscloud.app` configuration file for you.
</Note>

<Card title="Learn more: how to create the configuration file for Virtus Cloud." icon="link" href="https://docs.virtuscloud.app/en/getting-started/config-file">
  The virtuscloud.app file is a configuration file that will be used to
  configure your application; it will serve to define the name, description,
  version, main file, among other things.
</Card>

## 📄 Required Files

* main.rs (Example of main file).
* Cargo.toml (Dependencies file).
* [virtuscloud.app](https://docs.virtuscloud.app/en/getting-started/config-file) (file containing Virtus Cloud configuration).

## ▶️ How to start your application

* If the `START` field is not defined in the configuration file, Virtus Cloud will execute the command `cargo run --release` to compile and run the code in release mode. If the `START` field is defined in the configuration file, the value in it will be executed directly. For more information about configuration file parameters, visit [configuration parameters](https://docs.virtuscloud.app/en/getting-started/config-file#configuration-parameters).

## 🖥️ Preparing the project

Before hosting your project on Virtus Cloud, first check if the project files are properly configured so they can be suitably hosted.

<Warning>
  The configuration file (`virtuscloud.app/.config`) must be located at the root
  of the zip file. Otherwise, Virtus Cloud will not be able to find it during
  deploy.
</Warning>

## 📤 How to host your project

Now that you have prepared all the files for your Rust project, the next step is to upload them to Virtus Cloud and put your application online. There are several ways to upload, but we will cover two: via Dashboard or via CLI.

### Via painel

<Steps>
  <Step title="Acessar a Página de Upload">
    Acesse a [página de upload](https://virtuscloud.app/pt-br/upload) and upload your project zip file.
  </Step>

  <Step title="Configurar Seu Ambiente">
    After uploading your zip, you will need to configure the name, main file or runtime environment and other settings for your project.\
    If you are uploading a web project, make sure to select "Web Publication" and set a subdomain to your project.
  </Step>

  <Step title="Fazer Deploy do Projeto">
    Finally, click on the "Deploy" button to host your project on Virtus Cloud.\
    After deployment, you can monitor your project's status and logs from the dashboard.

    <Frame>
      <img src="https://cdn.virtuscloud.app/docs/articles/dashboard/uploading.gif" alt="Uploading application to Virtus Cloud" style={{ borderRadius: "0.2rem" }} />
    </Frame>
  </Step>
</Steps>

### Via CLI

To use this method, you need to create a config file named `virtuscloud.app` in the root directory of your project. This file will contain the necessary configuration for your project.

<Card title="Learn more about: how to create the configuration file for Virtus Cloud." icon="link" href="/en/getting-started/config-file">
  The virtuscloud.app file is a configuration file that will be used to configure your application; it will be used to define your environment.
</Card>

<Steps>
  <Step title="Instalar a CLI">
    First, you need to have the CLI installed in your environment. If you don't have it yet, run the following command in your terminal:

    ```
    npm install -g @virtuscloud/cli
    ```

    If you already have it, we recommend updating it. To do this, run the following command in your terminal:

    <Tabs>
      <Tab title="Windows">
        ```bash theme={null}
        virtuscloud update
        ```
      </Tab>

      <Tab title="Linux, macOS, and WSL">
        ```bash theme={null}
        curl -fsSL https://cli.virtuscloud.app/install | bash
        ```
      </Tab>
    </Tabs>
  </Step>

  <Step title="Autenticar">
    Agora, para autenticar e usar outros comandos da CLI, encontre sua chave de autorização [aqui](https://virtuscloud.app/pt-br/account/security) by clicking on "Request API Key". After obtaining your authorization key, run the following command:

    ```bash theme={null}
    virtuscloud auth login
    ```
  </Step>

  <Step title="Fazer Upload do Projeto">
    Finally, to deploy your application to Virtus Cloud using the CLI, you need to run the following command:

    ```bash theme={null}
    virtuscloud upload 
    ```

    Or if you created the zip manually, you can use:

    ```bash theme={null}
    virtuscloud upload --file <path/to/zip> 
    ```
  </Step>
</Steps>
