## Comandos Principais
A CLI da VirtusCloud fornece os seguintes comandos principais:

<Tabs>
    <Tab title="virtuscloud help">
        Comando para obter ajuda sobre qualquer comando.

        ```bash
        virtuscloud help
        ```

        Você verá as informações de ajuda sobre o comando.
        ```bash Saída
        A command line application to manage your VirtusCloud applications

        Usage:
          virtuscloud COMMAND [flags]
          virtuscloud [command]

        Available Commands:
          app         Do some actions with your applications
          auth        Manage your authentication with VirtusCloud
          backup      Manage your backups
          commit      Commit your application to VirtusCloud
          help        Help about any command
          upload      Upload your application to VirtusCloud
          zip         Zip the current folder

        Flags:
          -h, --help      help for virtuscloud
          -v, --version   Print CLI version

        Use "virtuscloud [command] --help" for more information about a command.
        ```
    </Tab>
    <Tab title="virtuscloud auth login">
        Comando para autenticar na CLI da VirtusCloud usando sua chave de API.

        ```bash
        virtuscloud auth login
        ```

        Você será solicitado a inserir sua chave de API.

        ```bash Insira seu token de API
        Your API Token:
        > Insira seu token de API da VirtusCloud
        ```

        ```bash Saída
        Your API Token has successfuly changed! You are now logged in a <username>
        With great power comes great responsibility!
        ```

        Após inserir sua chave de API, você estará autenticado na CLI da VirtusCloud. 😁
    </Tab>
    <Tab title="virtuscloud auth whoami">
        Comando para exibir as informações do usuário associado ao token VirtusCloud atual.

        ```bash
        virtuscloud auth whoami
        ```

        Você verá as informações do usuário associado ao token atual.
        ```bash Saída
        Currently logged as <username>
        ```
    </Tab>
    <Tab title="virtuscloud commit">
        Comando para fazer commit da sua aplicação na VirtusCloud.

        ```bash
        virtuscloud commit
        ```

        Sua aplicação será enviada para a VirtusCloud.
        ```bash Saída
        ✓ Your source has successfuly commited to VirtusCloud
        ```
    </Tab>
    <Tab title="virtuscloud zip">
        Comando para compactar a pasta atual em ZIP.

        ```bash
        virtuscloud zip
        ```

        A pasta atual será compactada.
        ```bash Saída
        ✓ Your source has successfuly zipped to documentation.zip
        ```
    </Tab>
</Tabs>

## Comandos de App
A CLI fornece os seguintes comandos para gerenciar suas aplicações:

<Tabs>
    <Tab title="virtuscloud app list">
        Comando para listar todas as suas aplicações VirtusCloud.

        ```bash
        virtuscloud app list
        ```

        Você verá uma lista de todas as suas aplicações VirtusCloud.
        ```bash Saída
        NAME                             App ID                              MEMORY    CLUSTER        LANG          WEBSITE
        Community Bot                    5bbd020326ee4692aba43e0ca0a75454    1024mb    fl-micron-1    javascript    false
        Management Bot                   5241e2ae060a4735ba672dd4abb7099b    1024mb    fl-micron-2    javascript    false
        Eval Bot Test                    7845e3b8683a4cb7a323656c09fdafce    1024mb    fl-micron-4    javascript    false
        Config Web                       9b72fc4efc7748da9c69fe21daab18f4    2048mb    fl-micron-2    javascript    true
        Proxy System                     a23d130fcc9d4be288ae4599a4292c32    3096mb    fl-micron-1    javascript    true
        Portfolio                        441fa128793q47adbb7519536eb6f9bc    2048mb    fl-micron-1    static        true
        ```
    </Tab>
    <Tab title="virtuscloud app">
        Comando para realizar ações com suas aplicações.

        ```bash
        virtuscloud app
        ```

        Você verá uma lista de todos os comandos disponíveis para gerenciar suas aplicações.
        ```bash Saída
        Do some actions with your applications

        Usage:
          virtuscloud app [flags]
          virtuscloud app [command]

        Available Commands:
          backup      Create a backup of you application
          commit      Commit your application to VirtusCloud
          delete      Delete your application
          list        List all your applications
          logs        See your application logs
          restart     Restart your application
          start       Start your application
          status      Show the status of your application
          stop        Stop your application
          upload      Upload your application to VirtusCloud

        Flags:
          -h, --help   help for app

        Use "virtuscloud app [command] --help" for more information about a command.
        ```
    </Tab>
</Tabs>

## Comando de Deploy
A CLI fornece o seguinte comando para fazer o deploy da sua aplicação:

<Tabs>
    <Tab title="virtuscloud upload">
        Comando para fazer upload da sua aplicação para a VirtusCloud.

        ```bash
        virtuscloud upload
        ```

        Sua aplicação será implantada na VirtusCloud.
        ```bash Saída
         ✓ Your application has been uploaded
        ```
    </Tab>
</Tabs>
