# virtuscloud auth login

> Command to authenticate in the Virtus Cloud CLI.

```bash theme={null}
virtuscloud auth login
```

You will be prompted to enter your API key.

```bash Insert your virtus cloud api token theme={null}
Your API Token:
> Insert your virtus cloud api token
```

```bash Output	  theme={null}
Your API Token has successfuly changed! You are now logged in a <username>
With great power comes great responsibility!
```

Tip: You can skip the prompt by passing your API key with the `--token` flag:

```bash theme={null}
virtuscloud auth login --token=<API key>
```
