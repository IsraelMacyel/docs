<Steps>
    <Step title="Obtenha a chave de API">
        Primeiro você precisa obter uma chave de API no [Painel do Desenvolvedor](https://virtuscloud.app/account/security). Você pode usar essa chave de API para se autenticar na CLI da VirtusCloud.
    </Step>
    <Step title="Autentique-se">
        Autentique-se na CLI da VirtusCloud usando o seguinte comando:
        ```bash
        virtuscloud auth login
        ```

        Você será solicitado a inserir sua chave de API.
        ```bash
        Your API Token:
        > Insira seu token de API da VirtusCloud
        ```

        Após inserir sua chave de API, você estará autenticado na CLI da VirtusCloud.

        Você pode pular o prompt passando sua chave de API com a flag `--token`:
        ```bash
        virtuscloud auth login --token=<chave de API>
        ```
    </Step>
</Steps>
