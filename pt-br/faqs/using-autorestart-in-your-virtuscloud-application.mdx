Uma **tecnologia exclusiva da VirtusCloud**, o Reinício Automático é um recurso poderoso que permite que sua aplicação **reinicie automaticamente em caso de falha**. Isso garante que **seu app** permaneça **acessível e funcional** mesmo em situações de **falhas inesperadas**.

## Ativando o Reinício Automático

<Steps>
    <Step title="Arquivo de configuração">
        Crie ou edite seu arquivo `virtuscloud.app` ou `virtuscloud.config`.
        <Card title="Como criar um arquivo de configuração" href="/getting-started/config-file">
    O arquivo virtuscloud.app é um arquivo de configuração que define nome, descrição, versão, arquivo principal, entre outras coisas.
</Card>
    </Step>
    <Step title="Localizar parâmetro">
        Localize o parâmetro `AUTORESTART` no arquivo de configuração. Ou adicione-o se não existir.
    </Step>
    <Step title="Definir valor">
        Defina o valor de `AUTORESTART` como `true`.

        ```systemd virtuscloud.app OU virtuscloud.config
        AUTORESTART=true
        ```
    </Step>
</Steps>

## Como Funciona o Reinício Automático

<Steps>
    <Step title="Aplicação para de funcionar">
        Quando sua aplicação falha, o Reinício Automático detecta o problema se AUTORESTART estiver habilitado.
    </Step>
    <Step title="Verificação de Tempo de Atividade">
        Se o **tempo de atividade da aplicação for > 60 segundos**, prossegue para o próximo passo.
    </Step>
    <Step title="Verificação do Status de Saída">
        Se o **status de saída da aplicação for 1**, prossegue para o próximo passo.
    </Step>
    <Step title="Verificação de Reinício Recente">
       Se a **aplicação não reiniciou nos últimos 60 minutos**, prossegue para o próximo passo.
    </Step>
    <Step title="Verificação de Exceção">
        Se os logs contiverem erros excluídos, o Reinício Automático não reiniciará a aplicação.

        Exemplos de erros excluídos:
        <CodeGroup>
        ```json SyntaxError
        SyntaxError: Unexpected token 'X'..
        SyntaxError: Unexpected identifier 'X'..
        ```
        ```json Versão não encontrada
        npm ERR! notarget No matching version found for
        ERROR: Could not find a version that satisfies the requirement
        ```
        ```json Módulo não encontrado
        Error: Cannot find module 'X'
        Module not found: Can't resolve 'X' in 'Y'
        ```
        ```json Arquivo de dependência inválido
        ERROR: Invalid requirement: 'X'
        npm ERR! code EJSONPARSE... npm ERR! Failed to parse json
        ```
        </CodeGroup>
    </Step>
    <Step title="Reinício da Aplicação">
        O AUTORESTART reinicia automaticamente sua aplicação. 😉
        <Info>O tempo de espera entre reinícios é de 60 minutos.</Info>
    </Step>
</Steps>

## Melhores Práticas

- Revise regularmente os logs da sua aplicação para entender as razões de falhas ou reinícios.
- Mantenha os parâmetros MAIN e de alocação de memória atualizados.

## Conclusão

O Reinício Automático na VirtusCloud é um recurso valioso que aumenta a confiabilidade da sua aplicação. Configure-o no arquivo `virtuscloud.app` ou `virtuscloud.config` para aproveitar ao máximo esse recurso.
