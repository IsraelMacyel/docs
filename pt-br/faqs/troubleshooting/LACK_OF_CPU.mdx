## Quando ocorre?

Este problema ocorre quando sua aplicação está utilizando mais CPU do que o disponível.

```bash
[VIRTUS-SHIELD] LACK_OF_CPU
```

## Por que ocorre?

Este problema ocorre quando sua aplicação está consumindo mais CPU do que o disponível. Isso pode acontecer quando sua aplicação está sob carga pesada ou quando não está otimizada para usar menos CPU.

## Como resolver

A CPU alocada para sua aplicação é determinada pelo seu plano atual. Para resolver isso, considere fazer upgrade para um plano superior na [página de planos](https://virtuscloud.app/pricing). Alternativamente, otimize sua aplicação para reduzir o uso de CPU.

### Resubmetendo sua aplicação

Após fazer o upgrade do seu plano, é importante remover sua aplicação e resubmetê-la para refletir a alocação de CPU atualizada.

Se continuar enfrentando problemas, não hesite em [contatar nossa equipe de suporte](/company/support).
