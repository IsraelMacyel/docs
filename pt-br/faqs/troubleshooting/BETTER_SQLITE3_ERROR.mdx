## Quando ocorre?

Este problema ocorre quando a biblioteca `better-sqlite3` ou uma biblioteca que depende dela, como `quick.db`, não está atualizada.

```bash
Error: Could not locate the bindings file. Tried:
 → /application/node_modules/better-sqlite3/build/better_sqlite3.node
 [...]
```

## Por que ocorre?

Este erro ocorre porque a biblioteca `better-sqlite3` não foi atualizada para a versão mais recente. Na versão **11.x.x e anteriores**, ela **não suportava o Node.js LTS v22**.

## Como corrigir

Atualize a biblioteca `better-sqlite3` para a versão mais recente. Lembre-se de atualizar bibliotecas que dependem dela, como `quick.db`.

### Verificar as versões mais recentes:
   - [npm better-sqlite3](https://www.npmjs.com/package/better-sqlite3)
   - [npm quick.db](https://www.npmjs.com/package/quick.db)

### Atualizar no `package.json`

```json Atualizar manualmente no package.json
"better-sqlite3": "^11.10.0",
"quick.db": "^9.1.7"
```

```bash Atualizar pelo terminal
npm install better-sqlite3@latest
```

### Remover arquivos para instalação limpa

Remova as pastas e arquivos: `node_modules`, `package-lock.json` e a pasta `.npm`.

### Reiniciar sua Aplicação

Reinicie sua aplicação clicando no botão azul.
