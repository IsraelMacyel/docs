## Não Autorizado (Unauthorized)

- Há 2 situações que podem resultar nessa mensagem ao tentar acessar um site/API:

1. A URL do site que você tentou acessar não está hospedada na VirtusCloud. Qualquer subdomínio de um site que não está hospedado na VirtusCloud e for acessado receberá a mensagem "Unauthorized". Se você adicionou o campo "SUBDOMAIN" após fazer o deploy da sua aplicação, esse campo não será lido e a URL não existirá, pois esse campo só é lido durante o deploy. Portanto, você precisa remover e refazer o deploy da sua aplicação com esse campo corretamente configurado.

2. Se você hospedou seu site recentemente, aguarde 1 minuto. A VirtusCloud está finalizando as configurações do seu site. Após esse período, tente acessar novamente.

## Timeout

- Há 4 situações que podem resultar nessa mensagem ao tentar acessar um site/API:

1. Seu site ou API pode ter erros impedindo-o de responder corretamente.

2. Se o site ou API estiver offline, você também receberá essa mensagem. É importante verificar os logs para identificar possíveis erros.

3. Na VirtusCloud, a porta padrão para sites e APIs é a porta `80` para tráfego HTTP. Se seu site ou API estiver usando uma porta diferente, você pode encontrar essa mensagem de erro.

4. Se você não configurar corretamente o host como `0.0.0.0` ao hospedar seu site, isso pode levar a erros de acesso.
