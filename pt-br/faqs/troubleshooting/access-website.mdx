## Não autorizado

Existem 2 situações que podem resultar nesta mensagem:

1. A URL do site que você tentou acessar não está hospedada na VirtusCloud. Se você adicionou o campo "SUBDOMAIN" após implantar sua aplicação, este campo não será lido, pois é processado apenas durante a implantação. Portanto, você precisa remover e reimplantar sua aplicação com este campo configurado corretamente.

2. Se você hospedou seu site recentemente, aguarde 1 minuto. A VirtusCloud está finalizando as configurações. Após este período, tente acessar novamente.

## Timeout

Existem 4 situações que podem resultar nesta mensagem:

1. Seu site ou API pode ter erros que impedem a resposta adequada.

2. Se o site ou API estiver offline, você também receberá esta mensagem. Verifique os logs para identificar possíveis erros.

3. Na VirtusCloud, a porta padrão para sites e APIs é a porta `80` para tráfego HTTP. Se seu site ou API usar uma porta diferente, você pode encontrar esta mensagem de erro.

4. Se você não configurar o host como `0.0.0.0` ao hospedar seu site, isso pode levar a erros de acesso.
