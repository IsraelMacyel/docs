## Quando ocorre?
Ao tentar conectar seu servidor Lavalink ao app hospedado na VirtusCloud:

```
Error: Unexpected server response: 400
Error: WebSocket closed abnormally with code 1006.
```

## Por que ocorre?
Você receberá este erro se estiver usando uma versão do Lavalink incompatível com a biblioteca que está usando. Por exemplo, se você usa o Lavalink versão 4.0.0 com um cliente Lavalink versão 3, pois o Lavalink v4 é completamente REST.

## Como corrigir
Atualize seu cliente Lavalink para a versão mais recente, ou use uma versão do Lavalink compatível com seu cliente.

### Dicas Extras:
- Lembre-se de abrir seu servidor Lavalink na porta 80.
- Conecte-se ao seu servidor Lavalink usando a porta 443 e a opção `secure: true`.

Parabéns! Você resolveu o problema do Lavalink Fechado Anormalmente.
