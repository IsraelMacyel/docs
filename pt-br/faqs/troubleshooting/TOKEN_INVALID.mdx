## Quando ocorre?
O token de autenticação do seu bot do Discord não foi encontrado ou parece ser inválido.

```bash discord.js
Error [TOKEN_INVALID]: An invalid token was provided.
```

```bash discord.py
LoginFailure: Improper token has been passed.
```

## Por que ocorre?
Este erro ocorre quando sua aplicação tenta autenticar com a API do Discord usando um token inválido ou desatualizado.

## Como corrigir

Certifique-se de que o token fornecido está correto e atualizado. Se suspeitar que o token é inválido, regenere-o no Portal do Desenvolvedor do Discord.

### Regenerar o Token
Se o token atual for inválido, gere um novo no [Portal do Desenvolvedor do Discord](https://discord.com/developers/applications).

### Atualizar o Token no seu Código
Se estiver usando um arquivo `.env`, atualize-o com o novo token.

### Manter a biblioteca atualizada

```bash Atualizar discord.js
npm install discord.js@latest
```

```bash Atualizar discord.py
pip install discord.py
```

### Reiniciar sua Aplicação

Após as alterações, reinicie sua aplicação.

Se continuar com problemas, [entre em contato com nosso suporte](/company/support).
