## Quando ocorre?

O erro ABUSE_REQUESTS ocorre quando sua aplicação é encerrada devido a um alto volume de requisições às APIs do Discord e/ou Amino.

```bash
[SQUARE-SHIELD] ABUSE_REQUESTS
```

## Por que ocorre?

Este erro ocorre quando sua aplicação excede os limites permitidos de requisições às APIs do Discord e/ou Amino.

## Como corrigir

### Monitorar e Otimizar seu Código

- Identifique seções problemáticas usando ferramentas de logging ou profiling.
- Otimize as chamadas de API e minimize requisições desnecessárias.

### Implementar Mecanismos de Cache

- Use cache local para armazenar dados frequentemente requisitados.
- Configure tempos de expiração do cache.

### Manter sua Aplicação Atualizada

```bash Atualizar discord.js
npm install discord.js@latest
```

```bash Atualizar discord.py
pip install discord.py
```
