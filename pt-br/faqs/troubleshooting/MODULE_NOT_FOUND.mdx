## Quando ocorre?
Este erro ocorre quando sua aplicação tenta usar uma biblioteca que não está instalada no ambiente.

```bash javascript
Error: Cannot find module 'discord.js'
```

```bash python
ModuleNotFoundError: No module named 'discord.py'
```

## Por que ocorre?

Isso pode acontecer quando você tenta usar uma biblioteca que não está instalada por padrão no ambiente. Por exemplo, a biblioteca `discord.js` não é instalada por padrão no ambiente JavaScript.

## Como resolver

Para corrigir isso, você precisa adicionar a biblioteca ausente aos arquivos de dependência do seu projeto. Esses arquivos listam as bibliotecas que serão instaladas no ambiente. No caso do Python, esse arquivo se chama `requirements.txt`, e para JavaScript, se chama `package.json`.

Veja um exemplo do conteúdo desses arquivos após adicionar as bibliotecas ausentes:

```json package.json
{
  "name": "minha-app",
  "version": "1.0.0",
  "dependencies": {
    "discord.js": "14.14.1",
    // outras dependências...
  }
}
```

```txt requirements.txt
discord.py
# outras dependências...
```

### Reinicie sua aplicação

Após adicionar as bibliotecas necessárias aos arquivos de dependência do seu projeto, você deve reiniciar sua aplicação. Isso permite que o ambiente reconheça e instale as bibliotecas recém-adicionadas.
