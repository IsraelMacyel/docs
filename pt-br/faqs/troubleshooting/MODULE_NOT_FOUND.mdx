## Quando ocorre?
Este erro ocorre quando sua aplicação tenta usar uma biblioteca que não está instalada no ambiente.

```bash javascript
Error: Cannot find module 'discord.js'
```

```bash python
ModuleNotFoundError: No module named 'discord.py'
```

## Por que ocorre?

Isso pode acontecer quando você tenta usar uma biblioteca que não está instalada por padrão no ambiente.

## Como corrigir

Adicione a biblioteca faltante aos arquivos de dependências do seu projeto.

```json package.json
{
  "name": "my-app",
  "version": "1.0.0",
  "dependencies": {
    "discord.js": "14.14.1"
  }
}
```

```txt requirements.txt
discord.py
```

### Reiniciar sua Aplicação

Após adicionar as bibliotecas necessárias, reinicie sua aplicação.
