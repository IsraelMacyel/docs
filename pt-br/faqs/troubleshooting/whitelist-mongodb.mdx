**A VirtusCloud** se destaca com sua **alocação de IP dinâmico**, atribuindo um **endereço único** a cada **reinício da aplicação**. Diferente de IPs estáticos, essa abordagem dinâmica aumenta a segurança alterando constantemente o footprint de rede.

## Quando ocorre?
Ao tentar conectar seu banco de dados MongoDB Atlas ao app hospedado na VirtusCloud:

```
MongoNetworkError: connection 0 to shard-xxx-xxx.mongodb.net:27017 closed
```

## Por que ocorre?
Você receberá esta mensagem se não incluiu os endereços do MongoDB Atlas na lista branca.

## Como corrigir
Para corrigir este erro, você precisa adicionar o IP `0.0.0.0/0` à lista branca, conforme a [documentação do MongoDB](https://www.mongodb.com/docs/atlas/security/ip-access-list/).
