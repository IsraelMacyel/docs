## Requisitos Mínimos de Recursos
Cada proyecto alojado en la Plataforma VirtusCloud tiene requisitos mínimos específicos de recursos para garantizar un rendimiento óptimo:

- **Bots:** Mínimo 256MB de RAM requeridos.
- **Sitios web:** Mínimo 512MB de RAM requeridos.
- **Bases de Datos Cache:** Mínimo 512MB de RAM requeridos.
- **Bases de Datos Generales:** Mínimo 1GB de RAM requeridos.

## ¿Por qué hay requisitos mínimos de RAM?
VirtusCloud impone requisitos mínimos de RAM para garantizar la estabilidad y el rendimiento óptimo de las aplicaciones. RAM insuficiente puede causar fallos en las aplicaciones y una experiencia degradada para el usuario.

Tenga en cuenta que aunque VirtusCloud ofrece planes con hasta **1TB de RAM**, la **asignación máxima de RAM** para cualquier **aplicación es de 32GB**. <ins>Si necesitas más de 32GB, contacta a nuestro equipo de soporte.</ins>

## Limitaciones de Red
La **velocidad de red aumenta 50 Mbps** por cada **256 MB adicionales** de RAM asignada.

- **256 MB RAM:** 50 Mbps
- **512 MB RAM:** 100 Mbps
- **1024 MB RAM:** 200 Mbps
- **2048 MB RAM:** 400 Mbps
- **4096 MB RAM:** 800 Mbps
- **8192 MB RAM:** 1600 Mbps
- **10240 MB RAM:** 2000 Mbps

## Limitaciones de Almacenamiento
- **Todos los proyectos:** Cada proyecto recibe 10GB de almacenamiento.

## Límites de Servicio

### LACK_OF_RAM
Si una aplicación excede el límite de RAM asignado, será marcada por violación de LACK_OF_RAM y apagada.

### LACK_OF_CPU
Si una aplicación excede su límite de procesamiento asignado, será marcada por violación de LACK_OF_CPU y apagada. VirtusCloud no permite alojar aplicaciones que minen criptomonedas.

VirtusCloud está dedicada a proporcionar un entorno seguro y equilibrado para todos los usuarios.
