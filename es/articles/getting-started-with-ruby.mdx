# Getting Started on Virtus Cloud with Ruby

> Learn how to get started on Virtus Cloud with Ruby

## 🚀 Introduction

* Before getting started, ensure that Ruby is installed on your system. If you don't have it yet, you can download it from the [official Ruby website](https://www.ruby-lang.org/en/), or use version managers like [rbenv](https://github.com/rbenv/rbenv) or [rvm](https://rvm.io/).
* Next, you will need to create an account on Virtus Cloud, which can be done through the [login page](https://virtuscloud.app/en/signup). You can use your email, GitHub, or both to create the account.
* Finally, you need to have an active paid plan on your account. You can view our plans and purchase one according to your needs [here](https://virtuscloud.app/en/pricing).

## ⚙️ virtuscloud.app file configuration

<Note>
  If you are uploading your application via the Virtus Cloud website, you can ignore this section. The site automatically creates the `virtuscloud.app` configuration file for you.
</Note>

## 📄 Required Files

* main.rb (Example of main file — your Ruby entry point).
* Gemfile (Dependencies file, if using Bundler).
* Gemfile.lock (Generated by Bundler; recommended to include for reproducible builds).
* [virtuscloud.app](https://docs.virtuscloud.app/en/getting-started/config-file) (file containing Virtus Cloud configuration).

## ▶️ How to start your application

* If the `START` field is not defined in the configuration file, Virtus Cloud will execute `ruby MAIN`, where the file specified in `MAIN` is the Ruby file (e.g. `main.rb`). If the `START` field is defined, the value in it will be executed directly. In applications using Bundler, it is common to define `START` as `bundle exec ruby main.rb` or another suitable startup command. For more information about configuration file parameters, visit [configuration parameters](https://docs.virtuscloud.app/en/getting-started/config-file#configuration-parameters).

<Info>For Ruby applications using **Bundler**, it is important to properly configure environment variables to optimize the dependency installation process on Virtus Cloud. Virtus Cloud runs the bundler installation using environment variables. To exclude unnecessary gem groups in production, configure the variable `BUNDLE_WITHOUT=development:test`. This also helps remove **deprecations** from **Bundler 2.x**.</Info>

## 🖥️ Preparing the project

Before hosting your project on Virtus Cloud, check if the project files are properly configured for hosting.

<Warning>The configuration file (`virtuscloud.app/.config`) must be located at the root of the zip file. Otherwise, Virtus Cloud will not be able to find it during deploy.</Warning>

## 📤 How to host your project

Now that you have prepared all the files for your Ruby project, the next step is to upload them to Virtus Cloud and put your application online. There are several ways to upload, but we will cover two: via Dashboard or via CLI.

### Via panel

<Steps>
  <Step title="Acceder a la Página de Carga">
    Accede a la [página de carga](https://virtuscloud.app/es/upload) and upload your project zip file.
  </Step>

  <Step title="Configurar tu Entorno">
    After uploading your zip, you will need to configure the name, main file or runtime environment and other settings for your project.\
    If you are uploading a web project, make sure to select "Web Publication" and set a subdomain to your project.
  </Step>

  <Step title="Desplegar tu Proyecto">
    Finally, click on the "Deploy" button to host your project on Virtus Cloud.\
    After deployment, you can monitor your project's status and logs from the dashboard.

    <Frame>
      <img src="https://cdn.virtuscloud.app/docs/articles/dashboard/uploading.gif" alt="Uploading application to Virtus Cloud" style={{ borderRadius: "0.2rem" }} />
    </Frame>
  </Step>
</Steps>

### Via CLI

To use this method, you need to create a config file named `virtuscloud.app` in the root directory of your project. This file will contain the necessary configuration for your project.

<Card title="Learn more about: how to create the configuration file for Virtus Cloud." icon="link" href="/en/getting-started/config-file">
  The virtuscloud.app file is a configuration file that will be used to configure your application; it will be used to define your environment.
</Card>

<Steps>
  <Step title="Instalar la CLI">
    First, you need to have the CLI installed in your environment. If you don't have it yet, run the following command in your terminal:

    ```
    npm install -g @virtuscloud/cli
    ```

    If you already have it, we recommend updating it. To do this, run the following command in your terminal:

    <Tabs>
      <Tab title="Windows">
        ```bash theme={null}
        virtuscloud update
        ```
      </Tab>

      <Tab title="Linux, macOS, and WSL">
        ```bash theme={null}
        curl -fsSL https://cli.virtuscloud.app/install | bash
        ```
      </Tab>
    </Tabs>
  </Step>

  <Step title="Autenticar">
    Ahora, para autenticarte y usar otros comandos de la CLI, encontrarás tu clave de autorización [aquí](https://virtuscloud.app/es/account/security) by clicking on "Request API Key". After obtaining your authorization key, run the following command:

    ```bash theme={null}
    virtuscloud auth login
    ```
  </Step>

  <Step title="Subir tu Proyecto">
    Finally, to deploy your application to Virtus Cloud using the CLI, you need to run the following command:

    ```bash theme={null}
    virtuscloud upload 
    ```

    Or if you created the zip manually, you can use:

    ```bash theme={null}
    virtuscloud upload --file <path/to/zip> 
    ```
  </Step>
</Steps>
