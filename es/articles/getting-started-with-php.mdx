## 🚀 Introduction

- Before you begin, make sure you have PHP on your system. If you don't have them yet, you can download them from the [official PHP website](https://www.php.net/).
- Next, you will need to create an account on VirtusCloud, which can be done through the [login page](https://virtuscloud.app/login). You can use either your email or Discord, or both, to create an account.
- Finally, you need to have an active paid plan on your account. You can view our plans and purchase one according to your needs [here](https://virtuscloud.app/plans).

## 📄 Required Files
- index.php (Example of main file).
- `composer.json` (*Optional dependency file).
- [virtuscloud.app](/getting-started/config-file) (a file containing your VirtusCloud configuration).

## ▶️ Start Application

- If the `START` field is not defined in the configuration file, a local PHP server will be started using the `php -S 0.0.0.0:80` command. If the `START` field is defined in the configuration file, the value in the `START` field will be executed directly. For more information on configuration file parameters, visit [configuration parameters](https://docs.virtuscloud.app/getting-started/config-file#configuration-parameters).

- If the `composer.json` file exists, all dependencies will be installed using the `php composer.phar install` command.

## 🖥️ Preparing Project for Upload

Before you can host your project on VirtusCloud, ensure your project files are correctly configured for hosting.

If your project includes a `composer.json` file, VirtusCloud will automatically install dependencies using Composer. However, if your project also has Node dependencies (i.e., a `package.json` file), you should specify the installation process in the `START` field of your `virtuscloud.app` file. For example:

```plaintext
START=npm install && php .....
```
<Warning>The configuration (`virtuscloud.app/.config`) file must be located in the root of the zip file. Otherwise, VirtusCloud will not be able to find it during deployment.</Warning>

## 📤 Uploading Project to VirtusCloud

After preparing your project files, you can now upload them to VirtusCloud and host your project.

<Tabs>
  <Tab title="Dashboard Upload">
    Access the [VirtusCloud
    Dashboard](https://virtuscloud.app/dashboard/upload) and upload your project
    files.
    <Frame>
      <img src="/images/uploading.gif" style={{ borderRadius: "0.2rem" }} />
    </Frame>
  </Tab>
  <Tab title="CLI Upload">
    <Steps>
      <Step title="First Step">
        First, you need to have the CLI installed in your environment. If you
        don't have it yet, run the following command in your terminal:
        ```
        npm install -g @virtuscloud/cli
        ```
        If you already have it, we recommend updating it. To do this, run the following command in your terminal:
        <Tabs>
          <Tab title="Windows">
            ```bash
            virtuscloud update
            ```
          </Tab>
          <Tab title="Linux, macOS, and WSL">
            ```bash
            curl -fsSL https://cli.virtuscloud.app/install | bash
            ```
          </Tab>
        </Tabs>
      </Step>
      <Step title="Second Step">
        Now, to authenticate and use other CLI commands, you will find your
        authorization key [here](https://virtuscloud.app/account) by clicking on
        "Request API Key". After obtaining your authorization key, run the
        following command: 
        ```bash 
        virtuscloud login
        ```
      </Step>
      <Step title="Third Step">
        Finally, to deploy your application to VirtusCloud using the CLI, you
        need to execute the following command, passing the path of your zip
        file: 
        ```bash 
        virtuscloud upload zip
        ```
      </Step>
    </Steps>
  </Tab>
</Tabs>
