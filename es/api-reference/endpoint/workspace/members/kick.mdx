# Remove Member

> Removes a workspace member from the workspace.

<ParamField header="Authorization" type="string" placeholder="API Key" required>
  The API key for your account. You can find this in your [account settings](https://virtuscloud.app/account/security).
</ParamField>

<ParamField body="workspaceId" type="string" placeholder="Workspace Id">
  The ID of the workspace.
</ParamField>

<ParamField body="memberId" type="string" placeholder="Member ID">
  The member ID.
</ParamField>
