---
title: "Get Service Status"
description: "Check the real-time status of VirtusCloud services"
api: "GET https://api.virtuscloud.app/v2/service/status"
authMethod: "none"
---

<Info>
  This route has a 5-minute cache and does not reflect the real-time status of
  status.virtuscloud.app.
</Info>

### Response

<ResponseField name="status" type="string">
The current status of VirtusCloud, with `online` indicating the service is online, `degraded` indicating issues, and `unknown` indicating unavailable.
</ResponseField>
<ResponseField name="message" type="string">
Message about the current status of VirtusCloud services.
</ResponseField>
<ResponseExample>
```json
{
    "status": "online",
    "message": "All services are online."
}
```
</ResponseExample>
