Al desplegar tu aplicación en VirtusCloud, ciertos archivos se eliminan automáticamente durante el proceso. Es importante excluirlos de tu paquete de despliegue.

## Lista de Archivos a Excluir:

- `.cache`
- `.config`
- `.composer`
- `.dockerenv`
- `.git`
- `.husky`
- `.logs`
- `.local`
- `.npm`
- `.next`
- `.pki`
- `.replit`
- `.upm`
- `.vscode`
- `__pycache__`
- `Cargo.lock`
- `.npmrc`
- `node_modules`
- `package-lock.json`
- `replit.nix`
- `replit_zip_error_log.txt`
- `target`
- `yarn.lock`
- `.venv`
- `.breakpoints`
- `pycache`

Estos archivos generalmente están relacionados con entornos de desarrollo, configuraciones de build y dependencias. VirtusCloud puede eliminarlos automáticamente durante el despliegue para optimizar el rendimiento.

Para más información, consulta la [documentación de VirtusCloud](https://docs.virtuscloud.app/).
