## Depuración en [**discord.js**](https://old.discordjs.dev/#/docs/discord.js/14.14.1/class/Client?scrollTo=e-debug)
Con discord.js, puedes usar los eventos "debug" y "error" para depurar. Aquí hay un ejemplo:

```js
// El cliente escucha el evento 'debug'
client.on('debug', (info) => {
    console.log(`Debug Info: ${info}`);
});

// El cliente escucha el evento 'error'
client.on('error', (error) => {
    console.error(`Error encontrado: ${error.message}`);
});
```

## Depuración en [**discord.py**](https://discordpy.readthedocs.io/en/stable/logging.html?highlight=debug)
Con discord.py, puedes usar el módulo logging para depurar. Aquí hay un ejemplo:

```py
import logging
import logging.handlers

logger = logging.getLogger('discord')
logger.setLevel(logging.DEBUG)
logging.getLogger('discord.http').setLevel(logging.INFO)

handler = logging.StreamHandler()
dt_fmt = '%Y-%m-%d %H:%M:%S'
formatter = logging.Formatter('[{asctime}] [{levelname:<8}] {name}: {message}', dt_fmt, style='{')
handler.setFormatter(formatter)
logger.addHandler(handler)

client.run("tu token aquí", log_handler=None)
```
En este código, toda la información de depuración y errores se registra en la consola.
