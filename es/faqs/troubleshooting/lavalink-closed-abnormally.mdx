## ¿Cuándo ocurre?
Al intentar conectar tu servidor Lavalink a tu app alojada en VirtusCloud:

```
Error: Unexpected server response: 400
Error: WebSocket closed abnormally with code 1006.
```

## ¿Por qué ocurre?
Recibirás este error si estás usando una versión de Lavalink incompatible con la biblioteca que estás usando.

## Cómo corregir
Actualiza tu cliente Lavalink a la última versión, o usa una versión de Lavalink compatible con tu cliente.

### Consejos adicionales:
- Recuerda abrir tu servidor Lavalink en el puerto 80.
- Conéctate a tu servidor Lavalink usando el puerto 443 y la opción `secure: true`.

Si continúas con problemas, [contacta a nuestro soporte](/company/support).
