## ¿Cuándo ocurre?
El token de autenticación de tu bot de Discord no se encontró o parece ser inválido.

```bash discord.js
Error [TOKEN_INVALID]: An invalid token was provided.
```

```bash discord.py
LoginFailure: Improper token has been passed.
```

## ¿Por qué ocurre?
Este error ocurre cuando tu aplicación intenta autenticarse con la API de Discord usando un token inválido o desactualizado.

## Cómo corregir

### Regenerar el Token
Si el token actual es inválido, genera uno nuevo en el [Portal de Desarrolladores de Discord](https://discord.com/developers/applications).

### Actualizar el Token en tu Código
Si usas un archivo `.env`, actualízalo con el nuevo token.

### Mantener la biblioteca actualizada

```bash Actualizar discord.js
npm install discord.js@latest
```

```bash Actualizar discord.py
pip install discord.py
```

Si continúas con problemas, [contacta a nuestro soporte](/company/support).
