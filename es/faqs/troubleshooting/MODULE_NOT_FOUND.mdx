## ¿Cuándo ocurre?
Este error ocurre cuando tu aplicación intenta usar una biblioteca que no está instalada en el entorno.

```bash javascript
Error: Cannot find module 'discord.js'
```

```bash python
ModuleNotFoundError: No module named 'discord.py'
```

## ¿Por qué ocurre?

Esto puede suceder cuando intentas usar una biblioteca que no está instalada por defecto en el entorno.

## Cómo corregir

Agrega la biblioteca faltante a los archivos de dependencias de tu proyecto.

```json package.json
{
  "name": "my-app",
  "version": "1.0.0",
  "dependencies": {
    "discord.js": "14.14.1"
  }
}
```

```txt requirements.txt
discord.py
```

### Reiniciar tu Aplicación

Después de agregar las bibliotecas necesarias, reinicia tu aplicación.

Si continúas con problemas, [contacta a nuestro soporte](/company/support).
