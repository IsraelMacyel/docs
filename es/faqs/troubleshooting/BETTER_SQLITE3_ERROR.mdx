## ¿Cuándo ocurre?

Este problema ocurre cuando la biblioteca `better-sqlite3` o una biblioteca que depende de ella, como `quick.db`, no está actualizada.

```bash
Error: Could not locate the bindings file. Tried:
 → /application/node_modules/better-sqlite3/build/better_sqlite3.node
 [...]
```

## ¿Por qué ocurre?

Este error ocurre porque la biblioteca `better-sqlite3` no se ha actualizado a la última versión. En la versión **11.x.x y anteriores**, la biblioteca **no era compatible con Node.js LTS v22**.

## Cómo corregir

Actualiza la biblioteca `better-sqlite3` a la última versión. Recuerda actualizar también las bibliotecas que dependen de ella, como `quick.db`.

### Actualizar en `package.json`

```json Actualizar manualmente en package.json
"better-sqlite3": "^11.10.0",
"quick.db": "^9.1.7"
```

```bash Actualizar usando la terminal
npm install better-sqlite3@latest
```

### Eliminar archivos para una instalación limpia

Elimina `node_modules`, `package-lock.json` y la carpeta `.npm`.

Reinicia tu aplicación haciendo clic en el botón azul.
