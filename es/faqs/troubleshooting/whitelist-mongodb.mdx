**VirtusCloud** se destaca con su **asignación de IP dinámica**, asignando una **dirección única** con **cada reinicio de la aplicación**.

## ¿Cuándo ocurre?
Al intentar conectar tu base de datos MongoDB Atlas a tu app alojada en VirtusCloud:

```
MongoNetworkError: connection 0 to shard-xxx-xxx.mongodb.net:27017 closed
```

## ¿Por qué ocurre?
Recibirás este mensaje si no has incluido las direcciones de MongoDB Atlas en la lista blanca.

## Cómo corregir
Debes agregar la IP `0.0.0.0/0` a la lista blanca según la [documentación de MongoDB](https://www.mongodb.com/docs/atlas/security/ip-access-list/).
