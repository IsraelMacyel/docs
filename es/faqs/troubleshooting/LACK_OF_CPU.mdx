## ¿Cuándo ocurre?

Este problema ocurre cuando tu aplicación está usando más CPU de lo disponible.

```bash
[SQUARE-SHIELD] LACK_OF_CPU
```

## ¿Por qué ocurre?

Esto puede suceder cuando tu aplicación está bajo una carga pesada o no está optimizada para usar menos CPU.

## Cómo corregir

La CPU asignada a tu aplicación está determinada por tu plan actual. Considera actualizar a un plan superior en la [página de planes](https://virtuscloud.app/pricing). Alternativamente, optimiza tu aplicación para reducir el uso de CPU.

### Reenviar tu aplicación

Después de actualizar tu plan, elimina y reenvía tu aplicación para reflejar la nueva asignación de CPU.

Si continúas con problemas, [contacta a nuestro soporte](/company/support).
