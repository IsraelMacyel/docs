## ¿Cuándo ocurre?

Este problema ocurre cuando tu aplicación está usando más CPU de la disponible.

```bash
[VIRTUS-SHIELD] LACK_OF_CPU
```

## ¿Por qué ocurre?

Este problema ocurre cuando tu aplicación consume más CPU de la disponible. Esto puede suceder cuando tu aplicación está bajo una carga pesada o cuando no está optimizada para usar menos CPU.

## Cómo resolverlo

La CPU asignada a tu aplicación está determinada por tu plan actual. Para resolver esto, considera actualizar a un plan superior en la [página de planes](https://virtuscloud.app/pricing). Alternativamente, optimiza tu aplicación para reducir el uso de CPU.

### Reenviar tu aplicación

Después de actualizar tu plan, es importante eliminar tu aplicación y reenviarla para reflejar la asignación de CPU actualizada.

Si continúas experimentando problemas, no dudes en [contactar a nuestro equipo de soporte](/company/support).
