## No Autorizado (Unauthorized)

- Hay 2 situaciones que pueden resultar en este mensaje al intentar acceder a un sitio web/API:

1. La URL del sitio que intentaste acceder no está alojada en VirtusCloud. Si agregaste el campo "SUBDOMAIN" después de desplegar tu aplicación, este campo no se leerá. Necesitas eliminar y volver a desplegar tu aplicación con este campo correctamente configurado.

2. Si recientemente alojaste tu sitio, espera 1 minuto. VirtusCloud está finalizando las configuraciones de tu sitio.

## Timeout

- Hay 4 situaciones que pueden resultar en este mensaje:

1. Tu sitio web o API puede tener errores que le impiden responder correctamente.
2. Si el sitio web o API está desconectado, también recibirás este mensaje.
3. El puerto predeterminado para sitios web y APIs en VirtusCloud es el puerto `80`. Si tu aplicación usa un puerto diferente, puedes encontrar este error.
4. Si no configuras correctamente el host como `0.0.0.0`, puede generar errores de acceso.
