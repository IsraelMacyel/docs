## No autorizado

Hay 2 situaciones que pueden resultar en este mensaje:

1. La URL del sitio que intentaste acceder no está alojado en VirtusCloud. Si agregaste el campo "SUBDOMAIN" después de desplegar tu aplicación, este campo no se leerá. Debes eliminar y reimplementar tu aplicación con este campo correctamente configurado.

2. Si alojaste tu sitio recientemente, espera 1 minuto. VirtusCloud está finalizando las configuraciones. Después de este período, intenta acceder de nuevo.

## Tiempo de espera agotado (Timeout)

Hay 4 situaciones que pueden resultar en este mensaje:

1. Tu sitio web o API puede tener errores que impidan responder correctamente.

2. Si el sitio web o API está offline, también recibirás este mensaje.

3. En VirtusCloud, el puerto predeterminado para sitios web y APIs es el puerto `80` para tráfico HTTP.

4. Si no configuras correctamente el host como `0.0.0.0`, puede producirse este error.
