# virtuscloud app upload

> Deploys your application to Virtus Cloud.

```bash theme={null}
virtuscloud app upload
```

Now just wait a few moments and your application will be deployed to Virtus Cloud.

```bash Output theme={null}
✓ Your application has been uploaded
```

Use `virtuscloud app upload --help` for more information about this command.
