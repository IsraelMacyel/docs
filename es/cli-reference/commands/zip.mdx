# virtuscloud zip

> Zip the current folder.

```bash theme={null}
virtuscloud zip
```

```bash Success Output theme={null}
Your source has successfuly zipped to <zip>
```

```bash Failed Output theme={null}
It was not possible to make the zip of your application
OR <zip>.zip already exists and its not possible to delete it
```
