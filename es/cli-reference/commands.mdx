## Comandos Principales

<Tabs>
    <Tab title="virtuscloud help">
        Comando para obtener ayuda sobre cualquier comando.
        ```bash
        virtuscloud help
        ```
    </Tab>
    <Tab title="virtuscloud auth login">
        Comando para autenticarte en la CLI de VirtusCloud con tu clave de API.
        ```bash
        virtuscloud auth login
        ```
        Se te pedirá que ingreses tu clave de API.
        ```bash
        Your API Token:
        > Inserta tu token de API de VirtusCloud
        ```
    </Tab>
    <Tab title="virtuscloud auth whoami">
        Comando para mostrar la información del usuario asociado al token actual.
        ```bash
        virtuscloud auth whoami
        ```
        ```bash Salida
        Currently logged as <username>
        ```
    </Tab>
    <Tab title="virtuscloud commit">
        Comando para hacer commit de tu aplicación en VirtusCloud.
        ```bash
        virtuscloud commit
        ```
    </Tab>
    <Tab title="virtuscloud zip">
        Comando para comprimir la carpeta actual en ZIP.
        ```bash
        virtuscloud zip
        ```
    </Tab>
</Tabs>

## Comandos de App

<Tabs>
    <Tab title="virtuscloud app list">
        Comando para listar todas tus aplicaciones de VirtusCloud.
        ```bash
        virtuscloud app list
        ```
    </Tab>
    <Tab title="virtuscloud app">
        Comando para realizar acciones con tus aplicaciones.
        ```bash
        virtuscloud app
        ```
    </Tab>
</Tabs>

## Comando de Despliegue

<Tabs>
    <Tab title="virtuscloud upload">
        Comando para subir tu aplicación a VirtusCloud.
        ```bash
        virtuscloud upload
        ```
        ```bash Salida
         ✓ Your application has been uploaded
        ```
    </Tab>
</Tabs>
