<Steps>
    <Step title="Obtén tu clave de API">
        Primero necesitas obtener una clave de API desde el [Panel de Desarrollador](https://virtuscloud.app/account/security). Puedes usar esta clave para autenticarte en la CLI de VirtusCloud.
    </Step>
    <Step title="Autentícate">
        Autentícate en la CLI de VirtusCloud usando el siguiente comando:
        ```bash
        virtuscloud auth login
        ```

        Se te pedirá que ingreses tu clave de API.
        ```bash
        Your API Token:
        > Inserta tu token de API de VirtusCloud
        ```

        Después de ingresar tu clave de API, estarás autenticado en la CLI de VirtusCloud.

        Puedes omitir el prompt pasando tu clave de API con el flag `--token`:
        ```bash
        virtuscloud auth login --token=<clave de API>
        ```
    </Step>
</Steps>
