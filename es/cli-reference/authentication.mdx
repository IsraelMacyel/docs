# Authentication

> Learn what it takes to authenticate to the Virtus Cloud CLI.

<Steps>
  <Step title="Get API key">
    First you need to get an API key from the [Developer Dashboard](https://virtuscloud.app/en/account/security). You can use this API key to authenticate to the Virtus Cloud CLI.
  </Step>

  <Step title="Autenticar">
    Authenticate to the Virtus Cloud CLI using the following command:

    ```bash theme={null}
    squarecloud auth login
    ```

    You will be prompted to enter your API key.

    ```bash theme={null}
    Your API Token:
    > Insert your square cloud api token
    ```

    After entering your API key, you will be authenticated to the Virtus Cloud CLI.

    You can skip the prompt by passing your API key with the `--token` flag:

    ```bash theme={null}
    squarecloud auth login --token=<API key>
    ```
  </Step>
</Steps>
