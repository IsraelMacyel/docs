# Installation

> Learn what it takes to install the Virtus Cloud CLI.

The Virtus Cloud CLI is a command-line tool that allows you to interact with Virtus Cloud services. You can use the CLI to deploy applications, manage services, and much more.

## Instalación

To use the CLI, you need to install it on your local machine.

You can install the CLI using the following commands:

<Frame>
  <img src="https://cdn.virtuscloud.app/docs/cli/install.gif" alt="Virtus Cloud CLI installation" />
</Frame>

<br />

<CodeGroup>
  ```bash macOS, Linux, and WSL  theme={null}
  curl -fsSL https://cli.virtuscloud.app/install | bash
  ```

  ```bash Windows with npm theme={null}
  npm install -g @virtuscloud/cli
  ```
</CodeGroup>

## Actualizar la CLI

To update the CLI, you can run the following command:

<CodeGroup>
  ```bash Windows theme={null}
  npm update -g @virtuscloud/cli
  ```

  ```bash Linux, macOS, and WSL theme={null}
  curl -fsSL https://cli.virtuscloud.app/install | bash
  ```
</CodeGroup>

And that's it! You have successfully updated the Virtus Cloud CLI. 🎉
