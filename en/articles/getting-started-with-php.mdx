# Getting Started on Virtus Cloud with PHP

> Learn how to get started on Virtus Cloud with PHP

## 🚀 Introduction

* Before getting started, ensure that PHP is installed on your system. If you don't have it yet, you can download it from the [official PHP website](https://www.php.net/).
* Next, you will need to create an account on Virtus Cloud, which can be done through the [login page](https://virtuscloud.app/en/signup). You can use your email, GitHub, or both to create the account.
* Finally, you need to have an active paid plan on your account. You can view our plans and purchase one according to your needs [here](https://virtuscloud.app/en/pricing).

## ⚙️ virtuscloud.app file configuration

<Note>
  If you are uploading your application via the Virtus Cloud website, you can ignore this section. The site automatically creates the `virtuscloud.app` configuration file for you.

## 📄 Required Files

* index.php (Example of main file).
* `composer.json` (Dependencies file *optional*).
* [virtuscloud.app](https://docs.virtuscloud.app/en/getting-started/config-file) (file containing Virtus Cloud configuration).

## ▶️ How to start your application

* If the `START` field is not defined in the configuration file, a local PHP server will be started with the command `php -S 0.0.0.0:80`. If the `START` field is defined, the value in it will be executed directly. For more information about configuration file parameters, visit [configuration parameters](https://docs.virtuscloud.app/en/getting-started/config-file#configuration-parameters).

* If the `composer.json` file exists, all dependencies will be installed using the command `php composer.phar install`.

## PHP with Swoole

* Swoole is a tool that improves standard PHP performance enabling the webserver to handle multiple requests asynchronously.

* With this tool, you can create microservices, websockets, background queues, among others. It also allows you to execute events just like JavaScript does.

* It is also important to mention that Swoole is compatible with other PHP frameworks. A good example of a PHP framework is Laravel which is compatible with Swoole thanks to Octane.

* You can use it instead of the standard PHP server by defining your custom START command. Example:

```bash theme={null}
npm run build && composer install --no-interaction --prefer-dist --optimize-autoloader && php artisan optimize && php artisan migrate --force && php -v && php artisan octane:start --host=0.0.0.0 --port=80 --workers=4 --task-workers=8 --server=swoole
```

* You can check out all the powerful functions of Swoole [here](https://www.php.net/manual/en/book.swoole.php).

## 🖥️ Preparing the project

Before hosting your project on Virtus Cloud, first check if the project files are properly configured for hosting.

If your project includes a `composer.json` file, Virtus Cloud will automatically install dependencies using Composer. However, if your project also has Node dependencies (i.e., a `package.json`), you must specify the installation process in the `START` field of your `virtuscloud.app` file. For example:

```plaintext theme={null}
START=npm install && php .....
```

<Warning>The configuration file (`virtuscloud.app/.config`) must be located at the root of the zip file. Otherwise, Virtus Cloud will not be able to find it during deploy.</Warning>

## 📤 How to host your project

Now that you have prepared all the files for your PHP project, the next step is to upload them to Virtus Cloud and put your application online. There are several ways to upload, but we will cover two: via Dashboard or via CLI.

### Via dashboard

<Steps>
  <Step title="Access the Upload Page">
    Access the [upload page](https://virtuscloud.app/en/upload) and upload your project zip file.
  </Step>

  <Step title="Configure Your Environment">
    After uploading your zip, you will need to configure the name, main file or runtime environment and other settings for your project.\
    If you are uploading a web project, make sure to select "Web Publication" and set a subdomain to your project.
  </Step>

  <Step title="Deploy Your Project">
    Finally, click on the "Deploy" button to host your project on Virtus Cloud.\
    After deployment, you can monitor your project's status and logs from the dashboard.

    <Frame>
      <img src="https://cdn.virtuscloud.app/docs/articles/dashboard/uploading.gif" alt="Uploading application to Virtus Cloud" style={{ borderRadius: "0.2rem" }} />
    </Frame>
  </Step>
</Steps>

### Via CLI

To use this method, you need to create a config file named `virtuscloud.app` in the root directory of your project. This file will contain the necessary configuration for your project.

<Card title="Learn more about: how to create the configuration file for Virtus Cloud." icon="link" href="/en/getting-started/config-file">
  The virtuscloud.app file is a configuration file that will be used to configure your application; it will be used to define your environment.
</Card>

<Steps>
  <Step title="Install the CLI">
    First, you need to have the CLI installed in your environment. If you don't have it yet, run the following command in your terminal:

    ```
    npm install -g @virtuscloud/cli
    ```

    If you already have it, we recommend updating it. To do this, run the following command in your terminal:

    <Tabs>
      <Tab title="Windows">
        ```bash theme={null}
        virtuscloud update
        ```
      </Tab>

      <Tab title="Linux, macOS, and WSL">
        ```bash theme={null}
        curl -fsSL https://cli.virtuscloud.app/install | bash
        ```
      </Tab>
    </Tabs>
  </Step>

  <Step title="Authenticate">
    Now, to authenticate and use other CLI commands, you will find your authorization key [here](https://virtuscloud.app/en/account/security) by clicking on "Request API Key". After obtaining your authorization key, run the following command:

    ```bash theme={null}
    virtuscloud auth login
    ```
  </Step>

  <Step title="Upload Your Project">
    Finally, to deploy your application to Virtus Cloud using the CLI, you need to run the following command:

    ```bash theme={null}
    virtuscloud upload 
    ```

    Or if you created the zip manually, you can use:

    ```bash theme={null}
    virtuscloud upload --file <path/to/zip> 
    ```
  </Step>
</Steps>
