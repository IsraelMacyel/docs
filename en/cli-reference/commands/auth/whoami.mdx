# virtuscloud auth whoami

> Command to display user information in the Virtus Cloud CLI.

```bash theme={null}
virtuscloud auth whoami
```

You will see the user information associated with the current Virtus Cloud token.

```bash Output theme={null}
Currently logged as <username>
```
