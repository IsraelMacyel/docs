# virtuscloud app snapshot

> Manages snapshots of your applications on Virtus Cloud.

```bash theme={null}
virtuscloud app snapshot create
# Creates a snapshot of your application on Virtus Cloud.
```

```bash theme={null}
virtuscloud app snapshot create --download
# Downloads the snapshot to your local machine after it's created.
```

```bash theme={null}
virtuscloud app snapshot list
# Lists all applications snapshots on Virtus Cloud.
```

```bash theme={null}
virtuscloud app snapshot list <appID>
# Lists all snapshots for a specific application identified by <appID>.
```

Use `virtuscloud app snapshot --help` for more information about this command.
