# virtuscloud app commit

> Commit your application to Virtus Cloud.

```bash theme={null}
virtuscloud app commit
```

```bash theme={null}
virtuscloud app commit --file <path/to/file>
# Specifies the file you want to upload to Virtus Cloud.
```

```bash -r or --restart theme={null}
virtuscloud app commit --restart
# Restarts your application automatically after the commit is complete.
```

Use `virtuscloud app commit --help` for more information about this command.
