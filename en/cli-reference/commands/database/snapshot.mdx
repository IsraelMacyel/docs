# squarecloud database snapshot

> Manages snapshots of your databases on Virtus Cloud.

```bash theme={null}
squarecloud database snapshot list
# Lists all database snapshots on Virtus Cloud.
```

```bash theme={null}
squarecloud database snapshot list <databaseID>
# Lists all snapshots for a specific database identified by <databaseID>.
```

Use `squarecloud database snapshot --help` for more information about this command.
