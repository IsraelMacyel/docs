# 😁 Welcome to Virtus Cloud Tutorials

> Explore Virtus Cloud tutorials and immerse yourself in a world of simplified enterprise hosting education. Start learning today!

# 🤔 What are Virtus Cloud "tutorials"?

* Our tutorials are essential resources designed to guide you from basic tools like hosting Discord bots to more advanced ones like using Selenium and hosting on Virtus Cloud. Get ready to master all the tools available in the largest enterprise hosting in Latin America.

## 📚 What Are the Tutorials About?

* The tutorials consist of tools available for use on Virtus Cloud, such as applications for platforms like Discord, Telegram, APIs built in Flask, and others.
* Each article teaches how to create, configure, and host your application on Virtus Cloud in the best possible way for developers.
* We are constantly updating and creating new tutorials based on user demand and tool evolution. If you want to suggest an article for us to add, you can do so in our [Discord community](https://go.virtuscloud.app/discord), where a team member will respond to your request, or by opening a pull request in our [documentation repository](https://github.com/squarecloudofc/docs).
