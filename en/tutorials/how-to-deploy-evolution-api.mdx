## Introduction

To develop and host {appType_0} on Virtus Cloud, it's essential to follow a structured sequence of configurations and prerequisites. This technical guide will cover the entire process, from initial setup to production deployment.

### Prerequisites

* **Virtus Cloud Account**: Register through the [signup page](https://virtuscloud.app/en/signup) using your email.
* **Active Paid Plan**: Ensures dedicated resources and optimized performance for your application. Check our [available plans](https://virtuscloud.app/en/pricing) and choose the most suitable for your needs.

## Why use Evolution API?

Evolution API creates an easier way to use many tools in one place, integrating n8n, chatwoot and other tools.
This project allows you to fastly create and connect with an instance through it or through it API, managing multiple bot instances in one place.

## Setting up the project

First, you need to get the project from some source. You can get it from the [official repository](https://github.com/EvolutionAPI/evolution-api) or from [our repository](https://github.com/virtuscloud-education/evolutionapi-web) which already have the files needed to deploy on the releases.

### Database configuration

To start setting up, we need a database for it. You can host one in Virtus Cloud if you have Standard plan or higher.
After creating, we need to set in our `.env` the URL as `DATABASE_CONNECTION_URI` and create the client certificate for the PostgreSQL connection. Here's an example of the configuration needed:

```systemd .env theme={null}
DATABASE_PROVIDER=postgresql
DATABASE_CONNECTION_URI='postgresql://virtuscloud:password@host:port/database?sslmode=require&sslidentity=path/to/client-identity.p12&sslpassword=p12password'
DATABASE_CONNECTION_CLIENT_NAME='evolution_exchange'
DATABASE_SAVE_DATA_INSTANCE=true
DATABASE_SAVE_DATA_NEW_MESSAGE=true
DATABASE_SAVE_MESSAGE_UPDATE=true
DATABASE_SAVE_DATA_CONTACTS=true
DATABASE_SAVE_DATA_CHATS=true
DATABASE_SAVE_DATA_LABELS=true
DATABASE_SAVE_DATA_HISTORIC=true
DATABASE_SAVE_IS_ON_WHATSAPP=true
DATABASE_SAVE_IS_ON_WHATSAPP_DAYS=7
DATABASE_DELETE_MESSAGE=true
```

With the environment variable and certificate set, you need to apply the migrations on your database. To do so, you need to have the `runWithProvider.js` file within the project folder and run the following command:

  </Tab>

  <Tab title="Linux">

### Server configuration

As shown in the repository `.env.example` file, you need to set some environment variables, server\_type, server\_port, server\_url and the language.

```systemd .env theme={null}
SERVER_NAME=evolution
SERVER_TYPE=http
SERVER_PORT=80
# Change the SERVER_URL to your actual server URL.
# you change it to your app url, selected when creating the app
# or when set a domain
SERVER_URL="https://my-evolution-api.virtuscloud.app"
LANGUAGE=en
# Other variables below...
```

It is important to configure a secure global API key to avoid non-authorized access.

```systemd .env theme={null}
# Other variables...
AUTHENTICATION_API_KEY=MySuperSecureAPIKEY
```

## Deploying

To deploy it in Virtus Cloud, you only will need to set the startup command and publish on web. To install and build, we recommend to use 3096MB of RAM.

```bash startup command theme={null}
npx prisma generate --schema prisma/postgresql-schema.prisma && npm run build && npm run start:prod
```

To use this method, you need to create a config file named `virtuscloud.app` in the root directory of your project. This file will contain the necessary configuration for your project.

## Additional info

After the first run, you can reduce the RAM to 1536MB or 2048MB and set the startup command to only:

```bash theme={null}
npm run start:prod
```

### Cache system

You can configure a cache system in Evolution API. To do so, you will need a Redis Database that you can also host in Virtus Cloud.\
To configure it, you will also need to download the certificate and set the URL to connect.

```systemd .env theme={null}
CACHE_REDIS_ENABLED=true
CACHE_REDIS_URI="redis://default:MySecurePassword@square-cloud-db-ID.virtuscloud.app:7170"
CACHE_REDIS_TTL=604800
# Prefix serves to differentiate data from one installation to another that are using the same redis
CACHE_REDIS_PREFIX_KEY=evolution
# Enabling this variable will save the connection information in Redis and not in the database.
CACHE_REDIS_SAVE_INSTANCES=false
```

## Troubleshooting

<CardGroup cols={1}>
  ### Custom Domain

  <Card horizontal>
    To use a custom domain (e.g., `mysite.com`) instead of the default URL `mysite.virtuscloud.app`, you need the **Standard plan or higher**. The subdomain is defined by the **SUBDOMAIN** field in the configuration file. See: [How to set up your custom domain](https://docs.virtuscloud.app/en/tutorials/platform/custom-domain).
  </Card>

  ### Minimum RAM Requirements

  <Card horizontal>
    **Minimum: 512MB RAM** for simple websites/APIs. For sites with frameworks (Next.JS, React, Vue, Angular, etc.), we always recommend **at least 1GB RAM**. For larger applications, allocate more RAM to prevent the application from running out of memory and crashing.
  </Card>

  ### Could not find this site.

  <Card horizontal>
    Check if the **subdomain/domain** matches what's configured in the **SUBDOMAIN** field or in the **custom domain settings**. If you just uploaded the site, wait up to **60 seconds** for Square to enable **first access**.
