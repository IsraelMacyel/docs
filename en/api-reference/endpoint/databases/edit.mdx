# Edit Database

> Edits a database hosted on Virtus Cloud, changing name and/or memory

## Request

### Headers

<ParamField header="Authorization" type="string" placeholder="API Key" required>
  The API key for your account. You can find this in your [account settings](https://virtuscloud.app/account/security).
</ParamField>

### Path

<ParamField path="database_id" type="string" placeholder="Database ID" required>
  The ID of the database.
</ParamField>

### Body

<ParamField body="name" type="string" placeholder="database name">
  The name of the Database. Must be \[a-z] \[A-Z] \[0-9].
</ParamField>

<ParamField body="ram" type="int" placeholder="RAM(in MB)">
  The amount of RAM to allocate, in megabytes. Minimums: Redis 512 MB, MongoDB and PostgreSQL 1024 MB.
</ParamField>

## Response

<ResponseField name="status" type="string">
  Indicates whether the call was successful.. `success` if successful, `error` if not.
</ResponseField>

<ResponseExample>
  ```json theme={null}
  {
    "status":"success"
  }
  ```
</ResponseExample>
