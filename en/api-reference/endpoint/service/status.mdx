# Get Service Status

> Check the real-time status of Virtus Cloud services

<Info>
  This route has a 5-minute cache and does not reflect the real-time status of
  status.virtuscloud.app.
</Info>

### Response

<ResponseField name="status" type="string">
  The current status of Virtus Cloud, with `online` indicating the service is online, `degraded` indicating issues, and `unknown` indicating unavailable.
</ResponseField>

<ResponseField name="message" type="string">
  Message about the current status of Virtus Cloud services.
</ResponseField>

<ResponseExample>
  ```json theme={null}
  {
      "status": "online",
      "message": "All services are online."
  }
  ```
</ResponseExample>
