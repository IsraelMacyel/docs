First you need to get an API key from the [Developer Dashboard](https://virtuscloud.app/account/security). You can use this API key to authenticate to the VirtusCloud API.

```bash
'Authorization': '<api_key>'
```

## API Usage
You can use the API key to authenticate to the VirtusCloud API. You can use the API key in the `Authorization` header.
Remembering that the use of the API is subject to the [Terms of Service](https://virtuscloud.app/legal) and the [Acceptable Use Policy](https://virtuscloud.app/legal/policy).
