# Authentication

> Learn what it takes to authenticate to the Virtus Cloud API.

First you need to get an API key from the [Developer Dashboard](https://virtuscloud.app/en/account/security). You can use this API key to authenticate to the Virtus Cloud API.

```bash theme={null}
'Authorization': '<api_key>'
```

## API Usage

You can use the API key to authenticate to the Virtus Cloud API. You can use the API key in the `Authorization` header.
Remembering that the use of the API is subject to the [Terms of Service](https://virtuscloud.app/legal) and the [Acceptable Use Policy](https://virtuscloud.app/legal/policy).

## OpenAPI Specification

The Virtus Cloud API publishes a machine-readable [OpenAPI](https://www.openapis.org/) specification that describes every endpoint, parameter, schema and authentication method. Use it to generate clients, import the API into tools like Postman or Insomnia, or to keep your own integrations in sync with the latest changes.

```bash theme={null}
https://api.virtuscloud.app/v2/openapi.json
```
